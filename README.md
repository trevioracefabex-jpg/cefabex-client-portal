# CEFABEX Innovations — Client Login Portal

A futuristic client command center built as a lightweight, responsive front-end prototype.

## Features
- Client overview dashboard
- Project progress & milestones
- Secure-document vault UI
- Service request / support workflow
- Client profile
- Responsive mobile navigation
- Futuristic blue / white / dark-navy visual system
- Neon glow, grid, glass panels, motion and micro-interactions

## Run locally
Open `index.html` in a browser, or use any static server:

```bash
python -m http.server 5500
```

Then open `http://localhost:5500`.

## GitHub Pages
Push the three site files (`index.html`, `style.css`, `app.js`) to a repository and enable GitHub Pages from the repository's Pages settings.

> This is a front-end prototype. Real authentication, password reset, uploads, protected files and API-backed project data should be connected to a secure backend before production use.
